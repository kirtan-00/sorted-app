sorted for Mac.

Public beta. We recommend the Terminal way: one line installs it and opens it in Chrome. Everything runs on your Mac; the shoot disk is only read and nothing is uploaded, ever.

Install

curl -fsSL https://kirtan-00.github.io/sorted/install.sh | bash

Open Terminal (press ⌘ Space, type Terminal, Enter), paste the line, press Enter. This may take 7 to 10 minutes the first time (it downloads about 1.3 GB of libraries and models). Leave the window open; the app opens in Chrome by itself when it is done, and a sorted icon lands on your Desktop. The same line run again updates the app and puts the Desktop icon back, in under a minute.

Reinstall from scratch, or update

curl -fsSL https://kirtan-00.github.io/sorted/install.sh | FRESH=1 bash

Removes the old app and the Desktop icon, then installs the newest build (7 to 10 minutes again). Your scans and project files are kept. Use this when the app will not open after an update, or the Desktop icon was deleted.

Uninstall

curl -fsSL https://kirtan-00.github.io/sorted/uninstall.sh | bash

Stops the app, removes it and the Desktop icon. Your scans stay in ~/Library/Application Support/photosort so a later install finds them; put DATA=1 before bash to remove those too. Project files you saved are ordinary files and are never touched.

Next time

Double-click the sorted icon the installer left on your Desktop, or double-click any sorted_<shoot>.sorted project file. Or paste the install line again in Terminal (fast, it just opens the app). Give it Full Disk Access the first time macOS asks, so it can read the SSD.

2

Open a shoot

Scan a disk or folder, pick the disk or folder, then it indexes. Photos take about ten minutes per 4,000 on an M1; clips longer. If you were given a project file (sorted_<shoot>.sorted, or an older .photosort-index.zip), double-click it or use Open a project file instead and skip the wait.

Tell us what happened

Top right, How it works, then Feedback, Save report to Desktop. Email that zip to purohit.krick@gmail.com. It holds what you clicked, searched and where it broke. No photos, no names, no paths.

Needs: an Apple silicon Mac (M1 to M4), macOS 14 or newer, about 2 GB free for the app and a further 5 to 20 GB for thumbnails of a big shoot. Intel Macs are not supported in the beta. Prefer a zip? Download it, unzip, then run Install sorted.command; macOS will ask you to allow it once under Privacy & Security. The installer counts itself once, anonymously. The app never phones home.
