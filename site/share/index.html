Share a project file with an editor.

A project file holds everything sorted learned about a shoot: thumbnails, video frames, search, faces, people names, your Same or Different answers. It does not hold the photos and clips. So the editor gets two things: the project file and the disk.

On your Mac

1

Open the shoot

It is under Recent on the welcome screen.

2

Left sidebar Scan, then Save project

No dialog, no wait: command S works too. It writes sorted_<shoot name>.sorted straight into a sorted folder beside the shoot on the disk, so it travels with the footage. Usually a few hundred MB, about 1 GB for a shoot with many clips. Want it somewhere else: Save to… opens a folder picker and remembers the place. Show in Finder points at the file.

Older build showing Export index instead? Re-run the install line to get the current build.

3

Hand over the disk and the file

Or a copy of the shoot folder plus the file on Drive. The file alone lets someone browse and search; cutting needs the footage.

On the editor's Mac

1

Install sorted

One line in Terminal, on the download page. A few minutes.

2

Plug in the disk, then double-click the project file

Double-click sorted_<shoot name>.sorted in the Finder and it opens straight into sorted (the Desktop icon the installer made handles this; re-run the install line if you installed before today to get it). Or open sorted first and click Open a project file on the welcome screen, or Open project… in the sidebar. When it asks for the photo folder, point at the shoot on the disk. Seconds, no rescan. Names, people and categories arrive with it. Given an older .photosort-index.zip instead? It opens the same way.

3

Work

Search, people, categories, export selects, Reorganise with Undo, straight to Drive. All on the originals.

One owner per project file for now. If the editor names more people or answers more Same or Different prompts, that stays on their Mac until they save their own project file; merging two project files of one shoot is on the roadmap.
